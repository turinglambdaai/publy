# Publy 使用指南

[English](USER-GUIDE.md) · **简体中文**

将 Markdown 转为微信公众号文章草稿与图片卡片，提供本地预览和自托管投递服务。

## 当前可用状态

CLI、默认主题、Obsidian 和自托管按现行许可证保持免费。公开托管订阅尚未开放，不销售无限量套餐。

## 平台与安装

提供 CLI 与 Obsidian 工作流；不是 Rivet/Glaze 桌面应用。当前发布附件包含 Obsidian 插件。服务端需要稳定出口 IP，以及公众号实际具备的官方 API 权限。

源码安装与运行命令见 [README](../README.zh-CN.md)；发布附件不等于完整部署服务。

## 第一次使用

1. 按源码安装说明安装，先在本地预览一篇非敏感 Markdown，再配置投递。
2. 配置自己的服务器与账号，将真实出口 IP 加入白名单，AppSecret 仅放在服务端。访问使用 HTTPS 或私有隧道。
3. 投递一份测试草稿，在微信后台确认结果。草稿投递成功不等于文章已公开发布或群发。

## 数据、备份与恢复

本地保留 Markdown 与媒体原件。服务配置、数据库、任务历史与加密材料应一起备份到受限、加密存储中；在隔离服务器验证恢复。结果未知的任务，应先核对远端草稿和历史，再决定是否重试。

## 联网、密钥与隐私

渲染可在本地完成。投递会经你选择的服务器把内容、媒体及账号凭据或派生令牌用于微信官方 API。应检查服务日志、重试历史和存储；不能笼统承诺“正文与密钥绝不落盘”。不要在 URL 或截图中分享 API key。

## 已知限制

公开托管注册、支付、租户隔离、留存删除与可靠任务恢复尚未通过验收（#7、#8）。不要将 AppSecret 发往未公告的托管端点或 issue。

## 升级与停止使用

升级前备份配置与数据，核对源码版本和依赖。先在隔离环境验证，再替换正在使用的版本。停止服务或程序后再清理本机数据；外部平台上的内容与凭据需在相应平台单独管理或撤销。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/publy/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
