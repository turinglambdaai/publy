Open source · AGPL-3.0 · CLI and Obsidian workflows

Write in Obsidian. Publish with your agent.

Publy is the agent-era publishing pipeline for WeChat Official Accounts: a CLI for typesetting and card rendering, a self-hosted server for draft delivery, and a theme gallery.

Free local tools and self-hosting. Public hosting is not open for registration or payment.

npm i -g @turinglambdaai/publy User guide Theme gallery
terminal
# install once — fonts, themes and samples bundled $ npm i -g @turinglambdaai/publy # the whole publishing flow, from the editor $ publy publish article.md ✓ typeset · cover uploaded · draft ready $ publy card post.md --theme naive ✓ 6 cards · 3:4 · 1.8s · pixel-exact glyphs
What Publy does

One pipeline, three moving parts.

Publish in one command

publy publish a.md — Markdown in, a typeset WeChat draft out. No GUI, no copy-pasting.

Image posts as a first-class citizen

Deterministic themed 3:4 cards — pixel-exact CJK glyphs in seconds, not AI images.

Themes as npm packages

Every theme ships with a preview; publy theme add installs after you've seen it.

Self-hosted delivery; hosting planned

Self-hosted account credentials and draft delivery; public hosting is planned.

Official API only

No account emulation, no browser automation — account permissions and deployment requirements still apply.

Open core, no lock-in

CLI and self-hostable server under AGPL-3.0 — the same code the cloud runs.

How it works

Preview locally. Deliver a draft. Confirm it.

terminal
# article: typeset and stage a WeChat draft $ publy publish article.md ✓ cover uploaded · draft ready in the official backend # image-post: themed 3:4 cards, deterministically rendered $ publy card post.md --theme naive ✓ 6 cards · 1.8s · pixel-exact glyphs # themes: install with a preview, not a leap of faith $ publy theme add @publy/theme-naive ✓ installed · preview at localhost:7818
Development preview. Local rendering and self-hosted delivery are available; public hosting is not open.

Start with one useful session.

从一次有效使用开始。

CLI, default themes, Obsidian and self-hosting remain free under their existing licences. Public hosted subscriptions are not open; there is no unlimited plan for sale.

CLI、默认主题、Obsidian 和自托管按现行许可证保持免费。公开托管订阅尚未开放，不销售无限量套餐。

CLI and Obsidian workflows; this is not a Rivet/Glaze desktop application. Published release assets currently include the Obsidian plugin. A server needs stable outbound IP and the account’s actual official API permissions.

提供 CLI 与 Obsidian 工作流；不是 Rivet/Glaze 桌面应用。当前发布附件包含 Obsidian 插件。服务端需要稳定出口 IP，以及公众号实际具备的官方 API 权限。

Configure your own server and account, whitelist its actual outbound IP, and keep AppSecret on that server. Use HTTPS or a private tunnel for access.

配置自己的服务器与账号，将真实出口 IP 加入白名单，AppSecret 仅放在服务端。访问使用 HTTPS 或私有隧道。
