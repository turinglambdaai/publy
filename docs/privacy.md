# Publy 托管服务 — 隐私政策

生效日期：2026-10-13

本政策说明 Publy 托管服务收集哪些数据、如何使用与保护。一句话原则：**只为把你的内容可靠送进草稿箱而存数据，不卖数据、不挖数据、不 beyond 服务范围使用数据。**

## 1. 我们收集什么

| 数据 | 内容 | 目的 |
|---|---|---|
| 联系方式 | 你购买/注册时填写的联系方式（微信/邮箱） | 发放 key、订单沟通、到期提醒 |
| 订单记录 | 档位、期限、支付流水号 | 对账、续费、客服 |
| 公众号凭据 | AppId 与 AppSecret | 调用微信官方 API 完成发布；**AppSecret 加密落盘，仅服务器进程可解密，永不明文下发** |
| 发布元数据 | 时间、账号名、标题、成功/失败 | 服务事件推送（webhook）、`publy history`、故障排查、计配额 |

## 2. 内容数据的路径

- 你的笔记原文**始终在你的本地设备**（Obsidian vault / 磁盘），排版渲染在本地完成。
- 发布时，当次内容的排版 HTML 与图片经本服务器转发至**微信官方 API**，随后即完成使命；服务器不保存正文全文，仅留存上表的元数据（标题等）用于审计。
- 服务器与微信之间的通信走微信官方 HTTPS API。没有模拟登录、没有灰产通道、没有第三方中间商。

## 3. 我们不做什么

- 不将任何数据出售、出租或提供给广告商；
- 不用你的内容训练任何模型；
- 不读取你的 Obsidian 库中未发布的内容（插件与 CLI 只处理你明确要求发布的文件）。

## 4. 留存与删除

- 发布历史元数据：Free 档保留 7 天、Pro 档保留至订阅到期后 90 天，随后自动清理。
- 解绑公众号账号 → 对应 AppSecret 即时从服务器删除。
- 要求彻底删除账户数据：联系购买页客服渠道，7 日内处理完毕。

## 5. 安全措施

- AppSecret 加密存储（服务器主密钥不与数据同库）；
- 全链路 HTTPS；API key 哈希校验；
- 每次发布留审计日志（谁、何时、发了什么标题），可在客户端随时查验。

## 6. 联系

隐私相关问题（含数据导出与删除请求）通过购买页展示的客服渠道联系。
