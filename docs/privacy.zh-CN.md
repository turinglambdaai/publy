# Publy 数据与隐私状态

[English](privacy.md) · **简体中文**

当前公开托管未开放，不能把旧隐私页面当成已经运行的客户服务承诺。本页描述源码与自托管的数据边界，不保证某个第三方部署按此配置。

| 数据 | 实际边界 |
|---|---|
| Markdown 与媒体原件 | 留在本地；投递时渲染内容和媒体会经选择的服务器发往微信 |
| 客户端 API key | 可存于 ~/.publy/config.json，应按秘密保护 |
| AppID / AppSecret | 静态 server.json 示例含明文秘密；其他绑定路径需核对加密及主密钥管理 |
| 任务、历史和缓存 | 可能落盘于队列、history.jsonl、数据库或缓存；不能笼统声称正文不落盘 |
| 对外通信 | 包安装、主题、所选服务器、微信官方 API 及配置的 webhook 各有数据接收方 |

自托管者负责限制文件权限、HTTPS 或私有隧道、鉴权、日志脱敏、备份加密与恢复验证。不要公开包含 key 的 WebSocket URL。解绑应用内账号不等于微信端凭据自动撤销，也不等于备份中的旧副本已删除；泄露时应在微信或对应服务商处轮换。

公开托管上线前，还需按实际实现明确经营者、收集字段与用途、第三方接收方、正文/媒体/日志/备份分别的保留期、导出和删除方式、客服与事件响应；不得提前承诺即时删除、7 天处理或全链路加密已经实现。非敏感问题走 [Issues](https://github.com/turinglambdaai/publy/issues)，不在公开 issue 提交个人数据或凭据。
