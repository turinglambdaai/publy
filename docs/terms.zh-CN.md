# Publy 服务状态与开通边界

[English](terms.md) · **简体中文**

公开托管服务尚未开放注册、购买或付款。本页替代旧版已生效托管条款；旧价格、退款承诺、多副本可用性与自动开通说明均已撤回，不能据此付款或提交账号秘密。

CLI、默认主题、Obsidian 与自托管继续按现行源码许可证使用。自托管运营者需明确自己的服务身份、支持和数据处理方式；本仓文档不自动构成其面向其他用户的服务条款。

未来开售前，必须同时公布中英文的实际经营者和联系方式、最终含税/费用说明、配额计量、付款周期与是否自动续费、取消退款、故障与支持范围、数据导出删除流程，并验证购买到交付的完整路径。实施方案归 [PRICING.zh-CN.md](../PRICING.zh-CN.md)，不是当前销售合同。

用户当前可用路径见[使用指南](USER-GUIDE.zh-CN.md)，数据去向见[隐私状态](privacy.zh-CN.md)。
